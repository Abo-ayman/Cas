# Sam Cash

تطبيق Flutter تجريبي لمحفظة وحوالات نقدية، مبني بواجهة عربية RTL وبألوان وتصميم قريب من الصور المرجعية التي تم اعتمادها.

## الموجود في النسخة

- شاشة رئيسية RTL بخلفية زرقاء هندسية.
- أرصدة مستقلة لـ USD / SYP / EUR.
- الأرصدة الابتدائية: 500 USD، 2,500,000 SYP، 10 EUR.
- تبديل العملة من بطاقات واضحة في أعلى الرصيد.
- إخفاء/إظهار الرصيد.
- إرسال واستقبال بخطوتين: الاسم ثم المبلغ.
- رسالة نجاح خضراء بعد العملية.
- سجل آخر التحويلات في الرئيسية وشاشة مستقلة للتحويلات.
- الإرسال يظهر `-` باللون الأحمر، والاستقبال `+` باللون الأخضر.
- فلترة الحوالات حسب العملة.
- ضغط مطول على الحوالة لفتح خيارات إيصال PDF.
- PDF عربي يتضمن بيانات العملية وصاحب الحساب.
- مشاركة PDF من الهاتف، ويمكن اختيار WhatsApp من قائمة المشاركة.
- صفحة حسابي لتغيير اسم صاحب الحساب.
- حفظ الأرصدة والاسم وسجل الحوالات محلياً عبر SharedPreferences.
- إعادة الرصيد إلى القيمة الابتدائية عند وصول رصيد العملة إلى صفر أثناء الاختبار.
- زر لإعادة الأرصدة التجريبية يدوياً.
- زر QR تجريبي في منتصف شريط التنقل.
- GitHub Actions يبني APK Release تلقائياً.

## تشغيل محلي

```bash
flutter create . --platforms=android --org com.samcash
flutter pub get
flutter analyze
flutter run
```

لبناء APK:

```bash
flutter build apk --release
```

## GitHub

ارفع محتويات هذا المشروع إلى المستودع، ثم ادفع إلى `main`. سيقوم GitHub Actions بتوليد APK في قسم **Actions > Build Android APK > Artifacts**.

> التطبيق تجريبي ومحلي ولا ينفذ تحويلات مالية حقيقية ولا يتصل بخدمة مصرفية.

## تغيير الشعار لاحقاً

الشعار الحالي Widget اسمه `BrandMark` في:

`lib/widgets/brand_mark.dart`

ويمكن استبداله بصورة/Asset حقيقية لاحقاً دون تغيير بنية الشاشات.
